# Tesseract language data

Optional Tesseract model files are intentionally not committed. For enhanced OCR, place these official `tessdata_fast` files in this directory:

- `chi_sim.traineddata`
- `eng.traineddata`
- `osd.traineddata`

Source: <https://github.com/tesseract-ocr/tessdata_fast>

The Windows OCR engine remains available when Tesseract is not installed, but fallback recognition quality may be lower.
