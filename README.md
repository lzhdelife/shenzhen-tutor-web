# 深圳家教单平台

这是一个由两部分组成的家教订单工具：

- `TutorPlatform`：老师接单、中介发单和管理员管理使用的 Web 平台。
- `TutorOrderWatcher`：在 Windows 上截取电脑版微信聊天正文、OCR 识别、跨屏拼接并上传订单的桌面助手。

仓库用于私有协作开发。真实用户数据库、账号、密码散列、高德 Key、微信截图、OCR 结果和聊天内容不会提交到 GitHub。

## 当前能力

- 姓名/机构名 + 手机号 + 短信验证码登录，兼容密码登录和微信开放平台扫码登录。
- 同一身份登录后可在老师接单端和中介发单端之间切换。
- 老师多选区域、K12 科目、年级段、教师性别，筛选条件按账号保存。
- 步行、骑行、驾车、公共交通路线与距离预览。
- 中介手工发单、粘贴文本批量解析、查看申请老师和联系方式。
- 管理员公告、反馈、订单状态、批量删除订单/账号、密码重置和地点重新核验。
- OCR 助手自动定位微信正文，适配 Windows 高 DPI，支持搜索群、连续翻屏、重叠拼接、去重和单张原图关联。
- 高德地点候选、地点核验和路线规划；未配置 Key 时使用本地估算。

## 快速启动网站

要求：Node.js 20 或更高版本。

```powershell
git clone <repository-url>
cd shenzhen-tutor-platform
npm start
```

打开 <http://localhost:8787>。第一次使用密码登录时，会按“名称 + 手机号”创建一组老师/中介账号。管理端第一次进入时设置至少 8 位密码。

网站首次启动会自动创建 `TutorPlatform/data/db.json`。该目录已被 Git 忽略。

## 启动 OCR 助手

要求：Windows 10/11、Windows PowerShell 5.1、已登录的电脑版微信。Tesseract 是可选增强依赖，Windows 自带中文 OCR 可单独工作。

1. 先启动网站，并确认浏览器能访问。
2. 双击 `TutorOrderWatcher/启动家教订单助手.bat`。
3. 填写网站地址和中介采集账号；密码只保存在当前进程内。
4. 打开电脑版微信，先执行一次“自动定位微信读取范围”和单次识别测试。
5. 确认截图只包含聊天正文后，再开始自动搬运。

OCR 助手会在 `TutorOrderWatcher/data/config.json` 保存非密码设置。这个文件和所有截图均不会提交。

## 重要限制

当前网站使用单个 JSON 文件同步写入数据，登录会话和地图缓存保存在进程内存中。这适合本地验证和小规模演示，不适合直接作为高并发公网生产系统。正式投产前应迁移到数据库、对象存储和持久会话，并补充限流、审计、备份和监控。

本仓库目前没有声明开源许可证。仓库代码只能由获得授权的协作者使用；如需公开发布，应先由项目所有者选择许可证并完成隐私与合规审核。
